# ButterBridge - Export Control Tower

Dashboard operativo para seguimiento de exportaciones de mantequilla, con foco en mercados internacionales, logística, cadena de frío, temperatura, cumplimiento documental y finanzas.

## Descripción

Este proyecto es un panel tipo control tower para visualizar:

- país de destino y mercado objetivo
- contenedor y embarque
- temperatura y cadena de frío
- ruta y tránsito
- cumplimiento documental
- KPI operativos y financieros
- alertas y riesgos

## Cómo ejecutar

1. Abre la carpeta del proyecto.
2. Ejecuta un servidor local:

```bash
python -m http.server 8000
```

3. Abre en el navegador:

```text
http://localhost:8000
```
